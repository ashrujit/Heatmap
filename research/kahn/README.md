# Kahn Research Provenance

This directory contains exploratory research artifacts authored by Claude unless
an individual file says otherwise.

Treat these files as hypothesis-generation material, not accepted Kahn policy.
Kahn remains a deterministic campaign governor: LevelLedger, BubbleTape, MBO,
and GEX-derived context can support management, add/suppress decisions, or
review questions only when the campaign contract and runtime state already
permit that kind of action.

The August 2026 replenishment/consumption work is specifically about whether a
tested LevelLedger rail is still defended when price returns to it. It is not an
entry directive, and it should not be read as permission to bypass HoldRoot or
campaign risk ownership.
