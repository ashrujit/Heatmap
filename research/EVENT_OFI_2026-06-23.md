# Event-Level OFI — First Full-Session Study

## Question

Does reconstructed event-level order-flow imbalance add confirmation evidence
during the transition from a LevelLedger displacement candidate to its normal
ten-second resolution, beyond the one-second snapshot proxy and contemporaneous
price progress?

This is the first event-data session, not a policy-validation sample.

## Data Admission

- NQU6, 2026-06-23, 09:30-16:00 New York.
- 33,998,199 book-event rows replayed through the study window.
- 33,791,980 valid post-seed deltas; one complete reset; zero continuity gaps.
- Recorder status showed zero event, tick, or snapshot drops and zero write
  failures.
- The reset occurred on the prior New York date partition. The validator was
  corrected to carry that seed through midnight.
- Rithmic-via-Quantower omitted some quote-id closures. Deterministic
  crossed-level eviction repaired 1,460 levels / 3,031 quote ids over the full
  carry-in replay. Only 91 valid metric events triggered repair (`0.0003%`).
- After repair, replay matched all 41,616 canonical snapshots at both best book
  and top five levels (`100.00%`). Clean OFI, which zeros the full contribution
  of a repair-triggering update, was numerically unchanged at the early anchors.

Crossed-level eviction is state repair, not observed cancellation flow. Its rate
must remain visible in every future event study.

## Population And Method

The existing one-second LL grammar defined the population, preserving the prior
snapshot study's outcome semantics:

- 402 clean resolved displacement episodes at onset: 142 confirmed, 260 reset.
- 251 survived to three seconds.
- 195 survived to five seconds: 142 confirmed, 53 reset.

Cont-style OFI was calculated from every reconstructed best-book transition and
normalized by contemporaneous best bid + ask depth. Wall-clock horizons were
3/5/10/20 seconds. Event-clock horizons were 250/500/1000/2000 valid deltas.
Snapshot OFI, five-level queue imbalance, aggressor-tape imbalance, and aligned
price progress were retained as controls.

## Early Confirmation Results

All features are aligned to the episode's eventual resolution side. AUC above
`0.5` favors episodes that later complete the normal confirmation.

| Persistence | Event OFI 3s | Event OFI 5s | Event OFI 1000e | Snapshot OFI 5s | Price progress 5s |
|---|---:|---:|---:|---:|---:|
| onset | 0.581 | 0.596 | 0.529 | 0.559 | 0.606 |
| +3 sec | 0.725 | 0.692 | 0.614 | 0.614 | 0.693 |
| +5 sec | 0.683 | 0.702 | 0.636 | 0.651 | 0.691 |

At five seconds, sign-conditioned confirmation lift was `19.4` percentage
points for event OFI 5s versus `19.1` points for snapshot OFI 5s. The similar
lift should not be read as an optimized threshold result; sign is only a simple
descriptive split.

### Beyond five-second price progress

| Feature at +5 sec | Conditional AUC | Residual AUC |
|---|---:|---:|
| Event OFI 3s | 0.631 | 0.628 |
| Event OFI 5s | 0.598 | 0.598 |
| Event OFI 500e | 0.601 | 0.571 |
| Event OFI 1000e | 0.609 | 0.617 |
| Snapshot OFI 5s | 0.573 | 0.538 |
| Tape imbalance 5s | 0.469 | 0.498 |
| Tape imbalance 10s | 0.486 | 0.532 |

Conditional AUC compares confirmed and reset episodes only within four-tick
five-second price-progress buckets. Residual AUC removes the pooled linear
relation between each feature and price progress. Both are coarse controls, not
a causal decomposition.

## Candidate-Cluster Robustness

The five-second population contains 195 episodes from 142 LL candidate ids.
A 2,000-draw candidate-cluster bootstrap gave:

| Feature | AUC | 95% candidate-cluster interval |
|---|---:|---:|
| Event OFI 3s | 0.683 | [0.595, 0.764] |
| Event OFI 5s | 0.702 | [0.619, 0.776] |
| Event OFI 1000e | 0.636 | [0.546, 0.724] |
| Snapshot OFI 5s | 0.651 | [0.566, 0.730] |
| Price progress 5s | 0.691 | [0.612, 0.766] |

Paired AUC differences were not resolved in one session:

- Event OFI 5s minus snapshot OFI 5s: `+0.050`, interval `[-0.039, +0.139]`.
- Event OFI 5s minus price progress 5s: `+0.010`, interval
  `[-0.054, +0.076]`.
- Event OFI 3s minus price progress 5s: `-0.008`, interval
  `[-0.100, +0.086]`.

These intervals address repeated candidates within this session only. They do
not estimate cross-session generalization.

## Post-Confirmation Continuation

There were 142 confirmed episodes with 30-second labels; 72 (`50.7%`) continued
in the aligned direction. Event OFI did not separate them:

- Event OFI 3s AUC: `0.498`.
- Event OFI 5s AUC: `0.470`.
- Event OFI 1000e AUC: `0.533`.
- Snapshot OFI 5s AUC: `0.494`.

This reinforces the prior gate's scope: pressure is potentially relevant to
candidate confirmation, not demonstrated as an add/runway or continuation
filter.

## Interpretation And Decision

The event stream earned admission, and event OFI contains positive information
in the intended transition window. Its conditional separation is stronger than
the snapshot proxy on this day, especially over the most recent three seconds.
However, price progress remains equally strong, paired improvements are
unresolved, multiple horizons were inspected, and only one session is
available.

Therefore:

1. Do not change LL's ten-second visual confirmation or EAR timing.
2. Continue full event capture across at least five varied RTH sessions.
3. Pre-register event OFI 5s at +3 and +5 seconds as the primary confirmation
   features; keep event OFI 3s and 1000-event OFI secondary.
4. Preserve candidate clustering, add session-clustered uncertainty once enough
   sessions exist, and hold out the final session(s).
5. Continue reporting raw and clean-repair OFI together.
6. Keep continuation/add research separate unless confirmation value survives
   held-out testing.
